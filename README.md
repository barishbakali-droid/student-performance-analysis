# 📊 Student Performance Analysis

## 📌 Project Overview

A beginner-friendly data analysis project focused on understanding student academic performance and identifying patterns in the data.

## 🎯 Objectives

- Analyze student performance data
- Identify academic trends
- Compare student scores
- Understand factors that may affect performance
- Present findings in a clear and simple way

## 📂 Dataset

The project uses a sample student performance dataset containing information such as:

- Student ID
- Gender
- Study Hours
- Attendance
- Previous Score
- Final Score

## 🔍 Analysis

The project will explore:

- Average student scores
- Attendance vs. performance
- Study hours vs. performance
- Highest and lowest scores
- Overall academic trends

## 📈 Key Insights

- 📚 Average study time: **3.90 hours**
- 📝 Average previous score: **75.25**
- 🎯 Average final score: **80.15**
- 📅 Average attendance: **85.15%**
- 📊 The analysis helps identify patterns between study habits, attendance, and academic performance.
